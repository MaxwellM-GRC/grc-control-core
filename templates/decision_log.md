# <POC name> — Decision Log

Record only material product, scope, risk, framework, operating-model, and
release decisions. Factual claims start as `Assumed`; AI recommendations and
unapproved choices start as `Proposed`.

| Date | Phase | Decision item | Evidence status and source | Decision status | Rationale or principle tradeoff | Product owner | Next test/action |
|---|---|---|---|---|---|---|---|
| `YYYY-MM-DD` | `Value / Define / Design / Align / Build & Learn` |  | `Verified / Assumed` | `Proposed / Approved / Rejected` |  |  |  |

Those remain in the POC evidence and case lifecycle.
